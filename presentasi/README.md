# Paparan BHP Medan — RDP Komisi XIII DPR RI (RUU Profesi Kurator)

Slide paparan Kepala Balai Harta Peninggalan Medan, disusun dari dokumen
*Bahan Masukan BHP Medan – RDP Komisi XIII DPR RI – RUU Profesi Kurator* (1 Oktober 2026).

- `Paparan_BHP_Medan_RUU_Profesi_Kurator.pptx` — 17 slide, 16:9, font Arial besar
  (judul 36 pt, isi 22–28 pt), warna navy–emas di atas putih untuk kontras tinggi.
  Setiap slide berisi catatan pembicara (speaker notes) berisi uraian lengkap dari dokumen.
- `build_slides.cjs` — skrip pembuat slide (pptxgenjs). Jalankan ulang bila isi perlu diubah:

  ```bash
  npm install pptxgenjs react react-dom react-icons sharp   # di folder terpisah
  NODE_PATH=<folder>/node_modules node build_slides.cjs
  ```

Versi Canva: https://www.canva.com/d/3PGEyDAsl1neFqh
